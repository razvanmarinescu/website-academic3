This project aims to develop state-of-the-art cryptanalytic attacks on cyphers and encryption functions by implementing soft differentiable versions and optimizing for the unknown key using gradient descent.

The approach replaces discrete operations with continuous relaxations so that gradients can guide the search over candidate keys. We will investigate how the choice of relaxation and optimization method affects key recovery, and evaluate candidate solutions using the original discrete encryption functions.
